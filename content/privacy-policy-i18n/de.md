# Datenschutzerklärung für TwoTicks

Zuletzt aktualisiert: 25. November 2026

TwoTicks („die Erweiterung“) wird von Osman Bodur, einer in Österreich lebenden Privatperson („ich“, „mich“), bereitgestellt. Sie erweitert WhatsApp Web (web.whatsapp.com) in Ihrem Chrome-Browser um zusätzliche Funktionen. In dieser Erklärung wird dargelegt, welche Daten die Erweiterung verarbeitet, wohin diese Daten gelangen und welche Informationen ich erhalte. Die Erweiterung steht in keiner Verbindung zu WhatsApp oder Meta und wird von diesen weder unterstützt noch gesponsert.

## Zusammenfassung

- Die Erweiterung läuft in Ihrem Browser auf web.whatsapp.com. Ich betreibe dafür keine Server und erhalte keinerlei Daten, die Sie damit verarbeiten: keine Chats, Kontakte, API-Schlüssel oder Nutzungsdaten.
- Es gibt keine Analysen, keine Werbung und kein Tracking, und es werden keine Daten verkauft.
- TwoTicks ist kostenlos. Es gibt weder ein Konto noch eine Zahlung noch eine Lizenz, und die Erweiterung greift nicht auf einen Zahlungsdienst zu.
- Abgesehen von den Video-Tutorials, die Sie abspielen, und den Links, auf die Sie klicken (siehe „Video-Anleitungen und Links“), greift die Erweiterung nur auf eine einzige Art von externem Dienst zu, und zwar erst, nachdem Sie selbst aktiv geworden sind: **den von Ihnen selbst ausgewählten KI-Dienst** für die optionalen KI-Funktionen (den KI-Assistenten, Antwortentwürfe in „Unbeantwortet“, eine Dringlichkeitsreihung für die Zusammenfassung aller Chats, Kompliment-Ideen und – sofern das Chrome-eigene Modell dies auf Ihrem Computer nicht leisten kann – das Transkribieren von Sprachnachrichten), und zwar mit Ihrem eigenen API-Schlüssel, jedes Mal, wenn Sie eine KI-Anfrage bestätigen. Vor jeder Anfrage zeigt TwoTicks in einem eigenen Fenster, das von der WhatsApp-Seite weder gelesen noch verändert werden kann, genau an, was gesendet wird, und sendet die Daten erst, nachdem Sie dort auf „Senden“ geklickt haben – es sei denn, Sie haben diese Überprüfung für diesen Dienst und dieses Modell deaktiviert („Nicht mehr anzeigen“). Die Einstellungsseite fragt zudem bei diesem Dienst die Liste der Modelle ab, die Ihr Konto anbietet (direkt nachdem Sie einen Schlüssel gespeichert haben, wenn Sie auf „Modelle laden“ klicken oder wenn Sie die KI-Einstellungen öffnen und noch keine Liste gespeichert ist) und sendet eine feste Testanfrage, wenn Sie auf „Verbindung testen“ klicken; dabei wird nur Ihr API-Schlüssel mitgesendet, niemals etwas aus Ihren Chats.
- Anstelle eines externen Dienstes können Sie sich für das **in Chrome integrierte Modell** entscheiden: Es ist Teil des Chrome-Browsers und wird auf Ihrem eigenen Computer ausgeführt. Die Erweiterung greift dann überhaupt nicht auf einen Dienst für den KI-Assistenten zurück.
- Wenn Sie die optionale **Verbindung für KI-Programme auf Ihrem Computer (MCP)** einschalten, können die KI-Programme, die Sie zulassen (zum Beispiel Claude Code oder VS Code), die Werkzeuge von TwoTicks über das separate Programm „TwoTicks MCP“ nutzen. Was sie lesen, geht an sie und, je nach Programm, an das Unternehmen, das seine KI betreibt. Ohne Ihre Bestätigung wird nichts gesendet, geplant, gelöscht, geändert oder exportiert. Siehe „KI-Programme auf Ihrem Computer (Verbindung, MCP)“.

## Welche Daten verarbeitet die Erweiterung?

Um ihre Funktionen bereitzustellen, liest die Erweiterung Daten aus, die WhatsApp Web Ihnen bereits in Ihrem Browser anzeigt:

- Chats und Nachrichten (Text, Bildunterschriften, Medien, geteilte Standorte, Kontaktkarten und Umfragen, Absendernamen und Zeitangaben): zum Exportieren von Chats, Herunterladen von Medien, Analysieren eines Chats, Erstellen einer Zusammenfassung Ihrer letzten Chats („Heute“), Auffinden von Chats, auf deren Antwort Sie noch warten, und – auf Ihren Wunsch hin – zum Senden von Nachrichten (sowie der von Ihnen ausgewählten Dokumente, Bilder, PDF-Dateien oder Sprachnachrichten) an Ihren KI-Dienst.
- Ihre Kontakte: die Personen in Ihrem Adressbuch und die Personen, mit denen Sie einen Einzelchat führen (Namen, Telefonnummern, WhatsApp-IDs): Diese können Sie als Excel- oder VCF-Datei exportieren. Personen, die Sie nur aus einer Gruppe kennen, werden nicht exportiert.
- Nachrichten, die ein Kontakt für alle löscht oder nachträglich bearbeitet: Das Tool „Gelöscht“ kann Ihnen den ursprünglichen Text anzeigen. Diese Funktion ist automatisch aktiv, sobald TwoTicks läuft – auch wenn Sie das Tool nie öffnen –, bis Sie sie dort deaktivieren.
- Telefonnummern und Nachrichten, die Sie in die Direktnachricht, die Schnellantworten, den Terminplaner, die Komplimente und die „Mehrere Chats“-Tools eingeben, sowie die Notizen, die Sie für KI-Kompliment-Ideen verfassen.
- Wenn Sie den KI-Assistenten einrichten: Ihren API-Schlüssel für den von Ihnen gewählten KI-Dienst sowie die entsprechenden Einstellungen.
- Wenn Sie die Verbindung für KI-Programme (MCP) einschalten: was die KI-Programme, die Sie zugelassen haben, anfordern, innerhalb der Werkzeuggruppen, die Sie eingeschaltet haben (siehe „KI-Programme auf Ihrem Computer (Verbindung, MCP)“).

## Wo werden die Daten gespeichert?

- **Im Website-Speicher von web.whatsapp.com**, in diesem Browser auf diesem Gerät:
  - geplante Nachrichten (Empfänger, Text, Uhrzeit, Status sowie – bei wiederkehrenden Nachrichten – die Häufigkeit der Wiederholung, die Anzahl der Sendungen und das letzte Mal, als die Nachricht übersprungen wurde);
  - Ihre Schnellantworten (Kurzname, Text und wie oft Sie die jeweilige Antwort verwendet haben);
  - die Einstellungen des Sichtschutzes (ob die Unschärfefunktion aktiviert ist und welche Bereiche sie abdeckt). Kein Nachrichteninhalt;
  - Kompliment-Routinen: die Person, die Tage und Uhrzeiten, ob TwoTicks Sie daran erinnert oder die Komplimente automatisch versendet, Ihre Komplimente, die Notizen, der Ton und die Sprache, die Sie für KI-Vorschläge festlegen, sowie wann das letzte Kompliment versendet wurde und wie viele es bisher waren;
  - das Protokoll der gelöschten und bearbeiteten Nachrichten (maximal 150 Einträge; kleine Bildvorschauen nur für die 20 neuesten). Es bleibt so lange erhalten, bis Sie es löschen, auch nachdem WhatsApp Web geschlossen wurde, und die WhatsApp-eigene Seite sowie andere auf web.whatsapp.com zugelassene Erweiterungen können auf diesen Seiten-Speicher zugreifen;
  - bis zu 8 Telefonnummern, die Sie kürzlich im Direktnachrichten-Tool verwendet haben;
  - für das Tool „Mehrere Chats“: die Zeitpunkte der Nachrichten, die es in den letzten 24 Stunden gesendet hat (ohne Text und ohne Empfänger), damit es sein Limit von 30 Nachrichten innerhalb von 24 Stunden einhält;
  - die Chats, die Sie im Tool „Unbeantwortet“ als „Keine Antwort nötig“ markiert oder dort mit „Später erinnern“ beiseitegelegt haben, sowie diejenigen, die Sie in dessen Ansicht „Sie warten“ als „Keine Antwort nötig“ markiert haben (jeweils höchstens 300: die WhatsApp-ID des Chats und die ID seiner letzten Nachricht; bei einem beiseitegelegten Chat zusätzlich das Datum, an dem er wieder erscheint; kein Nachrichtentext);
  - Ihre Einstellungen: zuletzt verwendetes Tool, Ländercode, Position der Panel-Schaltfläche und des Panels, Größe des Panels und ob es das Fenster ausfüllt, Sprache der Benutzeroberfläche und wann Sie diese ausgewählt haben, ob das Tool „Gelöscht“ gelöschte und bearbeitete Nachrichten speichert, wann Sie das Tool „Gelöscht“ zuletzt geöffnet haben, wann Sie das Panel zum ersten Mal geöffnet haben und ob und wann TwoTicks Sie gebeten hat, es zu bewerten (die Aufforderung erfolgt nur einmal);
  - Ein technischer Hinweis zur Inbetriebnahme: Die Namen von Teilen des WhatsApp-Web-eigenen Codes, auf die TwoTicks beim Laden der Seite gewartet hat und die WhatsApp nicht mehr enthält (höchstens fünf Namen, jeweils mit dem Zeitpunkt der Erfassung; ein Name wird nach sieben Tagen vergessen oder sobald WhatsApp wieder über einen solchen Teil verfügt). Dies verhindert, dass bei späteren Seitenladungen erneut darauf gewartet wird, und sagt nichts über Sie, Ihre Chats oder Ihre Nutzung von TwoTicks aus;
  - Die letzten Informationen, die das Panel von der Erweiterung erhalten hat: ob die Option „Senden, während WhatsApp Web geschlossen ist“ aktiviert ist, welcher KI-Dienst und welches Modell eingerichtet sind, welche Daten neben Text noch verarbeitet werden können (Bilder, PDF-Dateien, Sprachnachrichten), für das in Chrome integrierte Modell die Sprachen, die Chrome dafür angibt, und wie viel Text es verarbeiten kann, sowie die Namen und Texte Ihrer gespeicherten KI-Anweisungen. Kein API-Schlüssel.
- **Im eigenen Speicher der Erweiterung**, ausschließlich auf diesem Gerät. Die WhatsApp-Seite und andere Websites können darauf nicht zugreifen:
  - das Datum und die Uhrzeit der ersten Ausführung der Erweiterung sowie die jeweilige Version, damit die Installationen voneinander unterschieden werden können, falls jemals kostenpflichtige Tarife eingeführt werden sollten (siehe „TwoTicks ist kostenlos“);
  - der von Ihnen gewählte KI-Dienst; Ihr API-Schlüssel für jeden von Ihnen eingerichteten Dienst (jeder bleibt bestehen, bis Sie ihn entfernen); das für jeden Dienst ausgewählte Modell und die Liste der Modellnamen, die jeder Dienst Ihrem Konto angeboten hat; die Adresse eines KI-Servers auf Ihrem eigenen Computer; die ID des von Ihnen eingegebenen Anthropic-Arbeitsbereichs, falls vorhanden; die Größe des Textfensters, die Chrome für sein integriertes Modell angibt (eine Zahl); Ihre Anfragelimits; sowie die Dienste und Modelle, für die Sie die Überprüfung vor dem Senden deaktiviert haben;

Das Protokoll enthält weder den Text der Nachrichten noch die Antworten und auch weder die Namen noch die Inhalte der Dateien;

  - zum Versenden, während WhatsApp Web geschlossen ist: ob diese Funktion aktiviert ist, die Zeiten der bevorstehenden geplanten Nachrichten und automatischen Grußnachrichten (bis zu 30; nur die Zeiten, keine Empfänger und kein Text) sowie ob weitere folgen, und die Uhrzeit und das Ergebnis des letzten Mal, als die Erweiterung WhatsApp Web dafür geöffnet hat (wie viele Nachrichten wurden gesendet oder sind fehlgeschlagen);
  - für die Verbindung für KI-Programme (MCP): ob sie eingeschaltet ist und wann Sie zugestimmt haben, die Werkzeuggruppen, die Sie eingeschaltet haben, ob Sie in WhatsApp Web bestätigen, die KI-Programme, die Sie zugelassen oder abgelehnt haben (den Namen, den sich jedes selbst gibt, oder dass die Installation von TwoTicks MCP es eingerichtet hat, wann Sie entschieden haben und wann es TwoTicks zuletzt benutzt hat), ob TwoTicks WhatsApp Web für sie in einem eigenen Fenster geöffnet hat (die Nummer des Fensters, bis es sich schließt) und ein Protokoll der letzten 200 Aufrufe (Zeit, Programm, Werkzeug und Ergebnis). Das Protokoll enthält nichts von dem, was gelesen, gesendet oder gespeichert wurde;

WhatsApp Web leert seinen Webspeicher, wenn es diesen Browser abmeldet (zum Beispiel, wenn das Smartphone das verknüpfte Gerät entfernt); wenn sich dasselbe WhatsApp-Konto hier erneut anmeldet, stellt TwoTicks die fehlenden Daten wieder her und weist darauf hin. Die Kopie gehört nur zu einem einzigen Konto und wird unter einem Code abgelegt, der aus der WhatsApp-ID dieses Kontos berechnet wird: Wenn sich hier ein anderes Konto anmeldet, wird die Kopie des vorherigen Kontos gelöscht. Jede Änderung wird innerhalb einer Sekunde nachverfolgt; eine Kopie, die 30 Tage lang nicht aktualisiert wurde, wird nicht mehr verwendet und gelöscht, ebenso wie eine, die mehr als 250.000 Zeichen umfasst. Im Gegensatz zum restlichen Speicherplatz kann diese Kopie über die Seite von WhatsApp Web angefordert werden, genau wie der Website-Speicher, den sie kopiert.
- **Nur im Arbeitsspeicher**: Solange WhatsApp Web geöffnet ist, werden die letzten Nachrichten im Arbeitsspeicher gehalten, sodass eine später gelöschte Nachricht weiterhin angezeigt werden kann (nicht jedoch, wenn das Tool „Gelöscht“ deaktiviert ist); das Ergebnis der „Unbeantwortet“-Suche, der Chat-Analyse und der Zusammenfassung aller Chats, die transkribierten Wörter aus Sprachnachrichten, die letzte KI-Antwort sowie die KI-Komplimentvorschläge werden auf dieselbe Weise gespeichert. All dies wird beim Schließen der Registerkarte gelöscht.

## Wie Daten verwendet werden

Die Daten werden ausschließlich für die von Ihnen genutzte Funktion verwendet: zum Exportieren, Analysieren, Versenden der von Ihnen verfassten oder geplanten Nachrichten, zum Erinnern an die von Ihnen geplanten Komplimente (und zum Versenden dieser, falls Sie dies als Routine festgelegt haben), zum Anzeigen gelöschter oder bearbeiteter Nachrichten sowie – auf Ihre Anfrage hin – zum Abrufen einer Antwort von Ihrem KI-Dienst. Nachrichten, die Sie über die Erweiterung versenden, werden von WhatsApp Web über Ihr eigenes Konto versendet – genau wie Nachrichten, die Sie selbst eingeben – und erst, nachdem Sie den Vorgang gestartet haben (Nachrichten an mehrere Chats erst, nachdem Sie den Text und die Empfänger bestätigt haben).

**Versenden, während WhatsApp Web geschlossen ist.** Damit eine geplante Nachricht oder ein automatisches Kompliment auch dann zum vorgesehenen Zeitpunkt versendet wird, wenn kein WhatsApp-Web-Tab geöffnet ist, richtet die Erweiterung in Chrome kurz vor diesem Zeitpunkt einen Alarm ein. Ist zu diesem Zeitpunkt kein WhatsApp-Web-Tab geöffnet, wird WhatsApp Web in einem minimierten Fenster auf Ihrem Computer geöffnet; WhatsApp Web versendet die fällige Nachricht von Ihrem Konto aus, so wie es auch in einem von Ihnen geöffneten Tab geschehen würde, und das Fenster wird wieder geschlossen. Dazu werden weder an mich noch an einen anderen Server Daten gesendet. Sie können diese Funktion in den Einstellungen der Erweiterung („Wird gesendet“) deaktivieren. Wenn Sie dort zusätzlich „Chrome im Hintergrund weiterlaufen lassen“ aktivieren, läuft Chrome auch nach dem Schließen seiner Fenster weiter und startet, sobald Sie sich an Ihrem Computer anmelden (Chromes Berechtigung „Hintergrund“); deaktivieren Sie diese Option, um dies zu unterbinden.

Die Chat-Analyse, die Zusammenfassung aller Chats („Heute“), das Auslesen von Datums- und Zeitangaben aus Nachrichten, die daraus erstellten Kalenderdateien sowie die Antwortvorschläge im Tool „Unbeantwortet“ werden vollständig auf Ihrem Gerät ausgeführt. Zwei Funktionen können Daten versenden, jeweils nur, wenn Sie dies auswählen und im Fenster bestätigen, in dem angezeigt wird, was gesendet wird: eine Dringlichkeitsreihung für die Zusammenfassung durch Ihren KI-Dienst sowie von Ihrem KI-Dienst transkribierte Sprachnachrichten, bei denen das Chrome-eigene Modell auf Ihrem Computer nicht in der Lage ist, diese zu verarbeiten (beides wird unter „Der KI-Assistent mit Ihrem eigenen API-Schlüssel“ beschrieben). „Zum Planer hinzufügen“ füllt lediglich den Planer aus: Es wird nichts geplant oder gesendet, bis Sie dort auf die entsprechende Schaltfläche klicken. „KI-Prompt kopieren“ kopiert die letzten Nachrichten eines Chats in Ihre Zwischenablage; sie gelangen nur dorthin, wo Sie sie einfügen.

## TwoTicks ist kostenlos

TwoTicks ist kostenlos. Es gibt weder ein Konto noch eine Zahlung noch eine Lizenz, und die Erweiterung greift nicht auf einen Zahlungsdienst zu.

Die Erweiterung speichert den Zeitpunkt und die Version ihrer ersten Ausführung in einem eigenen Speicher auf Ihrem Gerät, damit Installationen voneinander unterschieden werden können, falls jemals kostenpflichtige Tarife eingeführt werden sollten. Diese Informationen verlassen Ihren Browser zu keinem Zeitpunkt.

Sollten in einer späteren Version kostenpflichtige Tarife eingeführt werden, wird diese Richtlinie aktualisiert, bevor eine Zahlungsdienstleister kontaktiert wird.

Der KI-Assistent ist optional und deaktiviert, bis Sie ihn in den Einstellungen einrichten. Sie können zwischen dem in Chrome integrierten Modell, für das kein Konto erforderlich ist, und einem Dienst wählen, den Sie mit Ihrem eigenen Konto nutzen:

- **Ihr API-Schlüssel** wird im eigenen Speicher der Erweiterung auf Ihrem Gerät gespeichert. Er wird ausschließlich bei jeder Anfrage an den entsprechenden Dienst gesendet (an Anthropic zusammen mit der Workspace-ID, falls Sie eine eingegeben haben). Auch ich habe keinen Einblick darin.
- **Was wird wann gesendet?** Erst wenn Sie eine Anfrage starten und bestätigen, sendet die Erweiterung folgende Informationen an Ihren Dienst: Ihre Anweisung (zum Beispiel „zusammenfassen“), das heutige Datum und Ihre Ortszeit (ein Teil der Anweisungen, den TwoTicks hinzufügt, damit das Modell erkennen kann, was bereits vergangen ist oder noch bevorsteht), den Namen des Chats und die von Ihnen ausgewählten Nachrichten (Datum, Uhrzeit, Name des Absenders, wie in WhatsApp angezeigt, oder – falls kein Name gespeichert ist – die Telefonnummer, Text und Bildunterschriften, geteilte Standorte mit ihren Koordinaten, Namen auf geteilten Kontaktkarten, Umfragefragen und -optionen; bei Fotos, Sprachnachrichten und anderen Medien nur deren Typ oder Dateiname; die Datei selbst nur, wenn Sie dies wie folgt auswählen). Wenn Sie im KI-Assistenten „Dokumente“ ankreuzen, wird auch der Text der dort ausgewählten Dokumente mitgesendet (Word-, Excel- und Textdateien des Chats; die Erweiterung konvertiert diese auf Ihrem Gerät in reinen Text und sendet diesen Text, nicht die Datei). Wenn Sie „Bilder“ aktivieren, werden auch die dort ausgewählten Bilder mitgesendet: Jedes wird auf Ihrem Gerät als kleineres JPEG-Bild (maximal 1568 Pixel pro Seite) neu gerendert, sodass nur das Bild selbst gesendet wird und keine von einer Kamera in die Datei geschriebenen Daten. PDF-Dateien, die Sie unter „Dokumente“ ausgewählt haben, werden unverändert mitgesendet, sofern der Dienst PDF-Dateien akzeptiert; wo dies nicht der Fall ist (und bei Verwendung des in Chrome integrierten Modells), liest die Erweiterung den Text aus der PDF-Datei auf Ihrem Gerät aus und sendet diesen Text, nicht die Datei (ein gescanntes PDF, das Bilder der Seiten und keinen Text enthält, wird dabei ausgelassen). Eine mit einem Passwort geschützte PDF-Datei wird ebenfalls nicht berücksichtigt – weder als Datei noch als Text. Wenn Sie „Sprachnachrichten“ ankreuzen, werden die dort ausgewählten Sprachnachrichten zunächst in Text umgewandelt. Sofern sich das in Chrome integrierte Modell auf Ihrem Computer befindet und dort zuhören kann, erfolgt dies auf Ihrem eigenen Computer, unabhängig davon, welchen KI-Dienst Sie für die Anfrage nutzen: Die Aufnahme selbst wird an keinen Dienst gesendet. Ist dies nicht der Fall (das Modell wurde nicht heruntergeladen oder Ihr Computer kann es nicht ausführen) und der von Ihnen genutzte KI-Dienst kann Sprache selbst transkribieren (derzeit Google Gemini und OpenAI), übernimmt dieser Dienst die Transkription: Die Aufnahme wird dann wie jede andere Anfrage an diesen Dienst gesendet, zusammen mit Ihrem Schlüssel. Bevor eine Aufnahme versendet wird, zeigt die Bestätigung diese mit einem Player zum Anhören an, zusammen mit Angaben dazu, wer sie gesendet hat, wann und wie lang sie ist; diese Bestätigung lässt sich nicht deaktivieren, und wenn Sie den Vorgang abbrechen, wird die Aufnahme nicht gesendet. Wo beides nicht möglich ist, werden Sprachnachrichten nicht angeboten. Das Gleiche gilt in „Unbeantwortet“ und in der Chat-Analyse, wo eine Aufnahme erst nach einem von Ihnen selbst ausgeführten Schritt an einen Dienst gesendet wird (in „Unbeantwortet“ über die Schaltfläche in der Chat-Zeile oder „Mit KI entwerfen“ für die an Sie gerichteten Sprachnachrichten, beides nur, solange dort „Sprachnachrichten niederschreiben“ angekreuzt ist; in der Chat-Analyse die Option, die deaktiviert ist, bis Sie sie aktivieren) und niemals von selbst. Danach werden nur die Wörter als Teil des Anfragetextes weitergeleitet, wobei die Bestätigung diese anzeigt, bevor etwas gesendet wird. Bilder werden nur dann bereitgestellt, wenn der von Ihnen genutzte Dienst und das von Ihnen verwendete Modell diese verarbeiten können; eine PDF-Datei wird dort als Datei übertragen, wo der Dienst PDF-Dateien akzeptiert, und an anderer Stelle als Text; pro Anfrage werden höchstens zehn Bilder und fünf Dokumente übertragen, jedoch niemals Inhalte aus Nachrichten, die nur zur einmaligen Anzeige gesendet wurden. Wie jede Website erfasst auch dieser Dienst Ihre IP-Adresse. Chrome bittet um Ihre Erlaubnis, bevor die Erweiterung überhaupt Kontakt zu einem Dienst aufnehmen darf. Die Bestätigungsanzeige zeigt die vollständige Anfrage, einschließlich der von TwoTicks hinzugefügten Anweisungen, genau so, wie sie jedes Mal gesendet wird; sie zeigt jedes beigefügte Bild und nennt jede PDF-Datei, zusammen mit dem Absender im Chat und dem Zeitpunkt der Übermittlung. Bevor eine Sprachaufzeichnung an einen Dienst gesendet wird, werden die Aufzeichnung selbst in einem Player, der Dienst und das Modell, an das sie gesendet wird, sowie die zugehörigen festgelegten Wörter angezeigt, sofern der Dienst solche vorgibt; eine Aufzeichnung, die Ihr Browser nicht abspielen kann, wird nicht gesendet. Die Anzeige wird von der Erweiterung selbst erstellt, außerhalb der Reichweite der WhatsApp-Seite und anderer dort ausgeführter Skripte, sodass nichts anderes die angezeigten Inhalte verändern oder in Ihrem Namen etwas versenden kann. ## KI-Programme auf Ihrem Computer (Verbindung, MCP)

Die Verbindung für KI-Programme ist optional und bleibt ausgeschaltet, bis Sie sie in den Einstellungen („Verbindung (MCP)“) einschalten, nachdem Sie dort gelesen haben, was sie bewirkt, und zugestimmt haben. Sie ermöglicht es KI-Programmen, die auf Ihrem eigenen Computer laufen und das Model Context Protocol (MCP) sprechen, zum Beispiel Claude Code oder VS Code, die Werkzeuge von TwoTicks zu nutzen. Dazu braucht es das separate, kostenlose Programm „TwoTicks MCP“, das Sie selbst von der Website von TwoTicks installieren (es ist nicht Teil der Erweiterung), und die Berechtigung von Chrome „Mit zusammenarbeitenden nativen Anwendungen kommunizieren“ (nativeMessaging), um die die Erweiterung bittet, wenn Sie die Verbindung einschalten, und die sie zurückgibt, wenn Sie sie ausschalten. Wenn Sie TwoTicks MCP selbst in einem Terminal installieren, öffnet die Installation die Einstellungen von TwoTicks auf diesem Tab in Ihrem Browser und wartet auf die Verbindung; sie schaltet nichts ein: Sie stimmen auf dieser Seite zu und beantworten die Frage von Chrome selbst.

- **So funktioniert es.** Solange die Verbindung eingeschaltet ist, startet Chrome das Programm TwoTicks MCP auf Ihrem Computer; nur TwoTicks kann es starten und mit ihm sprechen. Die KI-Programme, die Sie verwenden, starten TwoTicks MCP ebenfalls; es gibt ihre Anfragen an die Erweiterung weiter und die Antworten der Erweiterung an sie zurück, auf Ihrem Computer. Jedes KI-Programm muss zuerst von Ihnen zugelassen werden. Die Programme, die die Installation von TwoTicks MCP selbst eingerichtet hat (Claude Code und VS Code, sofern Sie sie haben), werden zusammen mit der Verbindung zugelassen, wenn Sie sie auf der Seite einschalten, die die Installation geöffnet hat und die diese Programme nennt; TwoTicks MCP erkennt sie an einem zufälligen Ticket, das die Installation in deren eigene Einstellungen geschrieben hat. Jedes andere Programm, ob mit einem KI-Modell im Internet oder auf Ihrem eigenen Computer, lassen Sie einmalig zu, wenn es sich zum ersten Mal verbindet, in den Einstellungen oder in einem Fenster, das TwoTicks in WhatsApp Web zeigt. In den Einstellungen können Sie jedes Programm jederzeit wieder entfernen. Ein Programm, das Sie selbst hinzufügen, gibt sich selbst einen Namen, und ein anderes Programm auf Ihrem Computer könnte sich denselben Namen geben: Lassen Sie nur Programme zu, die Sie selbst gestartet haben.
- **Was die KI-Programme tun können.** In den Werkzeuggruppen, die Sie einschalten (Lesen; Senden und Planen; Dateien; Dokumente und Sprachnachrichten lesen; der Sichtschutz; gelöschte und bearbeitete Nachrichten, die ausgeschaltet bleiben, solange Sie sie nicht einschalten): Ihre Chatliste, Chats und Nachrichten, die Ergebnisse der Chat-Analyse, „Heute“ und „Unbeantwortet“, Ihre geplanten Nachrichten, Kompliment-Routinen und Schnellantworten lesen; die Anhänge eines Chats abrufen (Bilder, Dokumente, Sprachnachrichten, Videos; nie Medien, die zum einmaligen Ansehen gesendet wurden); den Text von Dokumenten lesen und Sprachnachrichten vom in Chrome eingebauten Modell auf Ihrem Computer transkribieren lassen; den Sichtschutz ein- und ausschalten; und Nachrichten, Dateien von Ihrem Computer (Bilder, Töne als Audiodatei oder Sprachnachricht, PDF- und Word-Dokumente), Nachrichten an mehrere Chats, geplante Nachrichten, Kompliment-Routinen, Schnellantworten und Exporte vorbereiten. Chats, deren Mitglieder den erweiterten Chat-Datenschutz von WhatsApp eingeschaltet haben, werden nicht weitergegeben. Gruppenmitgliederlisten sind nicht verfügbar.
- **Ihre Bestätigung.** Nichts wird gesendet, geplant, gelöscht, geändert oder exportiert, ohne dass Sie bestätigen, was genau geschehen wird (den Text, die Empfänger und, bei mehreren Chats, dass die Empfänger zugestimmt haben, die Nachricht zu erhalten, und dass es keine Werbung ist). Ein Ton, der als Sprachnachricht gesendet werden soll, wird auf Ihrem Computer in das Sprachformat von WhatsApp umgewandelt. TwoTicks behält keine Kopie: Die Datei wird nur im Arbeitsspeicher gehalten, bis sie gesendet ist oder zehn Minuten vergangen sind, und das Protokoll enthält weder ihren Namen noch ihren Inhalt.
- **Was gespeichert bleibt.** Die Erweiterung speichert die Einstellungen und das Protokoll, die unter „Wo werden die Daten gespeichert?“ beschrieben sind; eine Aktion, die auf Ihre Bestätigung wartet, wird nur im Arbeitsspeicher gehalten, bis sie ausgeführt ist oder zehn Minuten vergangen sind. - **Ausschalten.** Das Ausschalten der Verbindung beendet sie sofort und gibt die Berechtigung an Chrome zurück. „Protokoll leeren“ leert das Protokoll; „Entfernen“ entfernt ein KI-Programm. Der Befehl „npx twoticks-mcp uninstall“ entfernt TwoTicks MCP mit seinen Registrierungen; gespeicherte Dateien bleiben, bis Sie sie löschen.
