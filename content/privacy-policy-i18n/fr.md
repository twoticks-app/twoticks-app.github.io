# Politique de confidentialité de TwoTicks

Dernière mise à jour : 23 novembre 2026

TwoTicks (ci-après « l’extension ») est proposée par Osman Bodur, un particulier résidant en Autriche (ci-après « je », « moi »). Elle ajoute des outils à WhatsApp Web (web.whatsapp.com) dans votre navigateur Chrome. La présente politique explique quelles données sont traitées par l’extension, où elles sont transmises et ce que je reçois. L’extension n’est ni affiliée à WhatsApp ou Meta, ni approuvée ni sponsorisée par ces sociétés.

## Résumé

- L'extension fonctionne directement dans votre navigateur, sur web.whatsapp.com. Je ne gère aucun serveur pour cette extension et je ne reçois aucune des données que vous traitez avec celle-ci : ni discussions, ni contacts, ni clés API, ni données d'utilisation.
- Il n'y a ni analyse, ni publicité, ni suivi, et aucune donnée n'est vendue.
- TwoTicks est gratuit. Il n'y a ni compte, ni paiement, ni licence, et l'extension ne fait appel à aucun service de paiement.
- Hormis les tutoriels vidéo que vous visionnez et les liens sur lesquels vous cliquez (voir « Tutoriels vidéo et liens »), l’extension ne contacte qu’un seul type de service externe, et ce uniquement après une action de votre part : **le service d’IA que vous choisissez vous-même** pour les fonctions IA optionnelles (l’assistant IA, les brouillons de réponse dans « Sans réponse », un niveau d’urgence pour le résumé de toutes les conversations, des idées de compliments et, lorsque le modèle propre à Chrome ne peut pas le faire sur votre ordinateur, la transcription des messages vocaux), à l’aide de votre propre clé API, chaque fois que vous confirmez une requête IA. Avant chaque requête, TwoTicks affiche exactement ce qui sera envoyé, dans une fenêtre distincte que la page WhatsApp ne peut ni lire ni modifier, et n’effectue l’envoi qu’après que vous ayez cliqué sur « Envoyer » dans cette fenêtre, sauf si vous avez désactivé cette vérification pour ce service et ce modèle (« Ne plus afficher »). La page des paramètres demande également à ce service la liste des modèles proposés par votre compte (juste après avoir enregistré une clé, lorsque vous cliquez sur « Charger les modèles », ou lorsque vous ouvrez les paramètres d’IA et qu’aucune liste n’est encore enregistrée) et envoie une requête de test fixe lorsque vous cliquez sur « Tester la connexion » ; seules vos clés API sont transmises lors de ces opérations, jamais aucune information issue de vos conversations.
- Au lieu d'un service externe, vous pouvez opter pour **le modèle intégré à Chrome** : il fait partie intégrante du navigateur Chrome et fonctionne directement sur votre ordinateur. L'extension ne contacte alors aucun service pour l'assistant IA.
- Si vous activez la **connexion facultative pour les programmes d'IA sur votre ordinateur (MCP)**, les programmes d'IA que vous autorisez (par exemple Claude Code ou VS Code) peuvent utiliser les outils de TwoTicks via le programme distinct « TwoTicks MCP ». Ce qu'ils lisent leur est transmis et, selon le programme, à l'entreprise qui exploite son IA. Rien n'est envoyé, programmé, supprimé, modifié ou exporté sans votre confirmation. Voir « Programmes d'IA sur votre ordinateur (Connexion, MCP) ».

## Quelles données l'extension traite-t-elle ?

Pour proposer ses fonctionnalités, l'extension lit les données que WhatsApp Web affiche déjà dans votre navigateur :

- Conversations et messages (texte, légendes, fichiers multimédias, positions partagées, fiches de contact et sondages, noms des expéditeurs et horaires) : pour exporter des conversations, télécharger des fichiers multimédias, analyser une conversation, préparer un récapitulatif de vos conversations récentes (« Aujourd’hui »), trouver les conversations en attente de votre réponse et, si vous le souhaitez, envoyer des messages (ainsi que les documents, images, fichiers PDF ou messages vocaux de votre choix) à votre service d'IA.
- Vos contacts : les personnes figurant dans votre carnet d'adresses et celles avec lesquelles vous discutez en tête-à-tête (noms, numéros de téléphone, identifiants WhatsApp) : pour les exporter sous forme de fichier Excel ou VCF. Les personnes que vous ne connaissez que par le biais d'un groupe ne sont pas exportées.
- Les messages qu'un contact supprime pour tout le monde ou modifie par la suite : l'outil « Supprimés » vous permet alors de voir le texte d'origine. Cette fonctionnalité s'active automatiquement dès le lancement de TwoTicks, même si vous n'ouvrez jamais cet outil, et reste active jusqu'à ce que vous la désactiviez depuis l'application.
- Les numéros de téléphone et les messages que vous saisissez dans les messages privés, les réponses rapides, le planificateur, les compliments et les outils « Plusieurs discussions », ainsi que les notes que vous rédigez pour obtenir des idées de compliments générées par l'IA.
- Si vous configurez l'assistant IA : votre clé API pour le service d'IA que vous avez choisi, ainsi que vos paramètres pour celui-ci.
- Si vous activez la connexion pour les programmes d'IA (MCP) : ce que demandent les programmes d'IA que vous avez autorisés, dans les groupes d'outils que vous avez activés (voir « Programmes d'IA sur votre ordinateur (Connexion, MCP) »).

## Où sont stockées les données ?

- **Les fichiers que vous exportez** (JSON, TXT, Excel, VCF, ZIP, rapports Markdown et fichiers de calendrier) sont enregistrés sur votre ordinateur via la fonction de téléchargement habituelle de Chrome. C'est vous qui décidez où ils seront stockés.
- **Dans le stockage local du site web.whatsapp.com**, dans ce navigateur et sur cet appareil :
  - messages programmés (destinataire, texte, heure, statut et, pour un message récurrent, la fréquence de répétition, le nombre de fois où il a été envoyé et la dernière fois où il a été ignoré) ;
  - vos réponses rapides (nom abrégé, texte et fréquence d'utilisation de chacune d'entre elles) ;
  - les paramètres de l'écran de confidentialité (si le flou est activé et quelles parties il masque). Pas de contenu de message ;
  - routines de compliments : la personne, les jours et les horaires, si TwoTicks vous envoie un rappel ou les envoie automatiquement, vos compliments, les notes, le ton et le langage que vous définissez pour les suggestions de l'IA, ainsi que la date du dernier compliment envoyé et le nombre total de compliments envoyés jusqu'à présent ;
  - l'historique des messages supprimés et modifiés (150 entrées au maximum ; petits aperçus d'images uniquement pour les 20 plus récents). Il est conservé jusqu'à ce que vous l'effaciez, même après la fermeture de WhatsApp Web, et la page officielle de WhatsApp ainsi que les autres extensions autorisées sur web.whatsapp.com peuvent accéder à ce stockage local ;
  - jusqu'à 8 numéros de téléphone que vous avez récemment utilisés dans l'outil de messagerie directe ;
  - pour l'outil « Plusieurs discussions » : les heures auxquelles il a envoyé des messages au cours des dernières 24 heures (sans texte ni destinataire), afin de respecter sa limite de 30 messages par 24 heures ;
  - les discussions que vous avez marquées comme « Pas besoin de répondre » dans l'outil « Sans réponse » ou que vous y avez mises de côté avec « Me le rappeler plus tard », ainsi que celles que vous avez marquées comme « Pas besoin de réponse » dans sa vue « Vous attendez » (300 au maximum pour chacun : l'identifiant WhatsApp de la conversation et l'identifiant de son dernier message ; pour une conversation mise de côté, indiquez également la date à laquelle elle réapparaît ; pas de texte de message) ;
  - vos paramètres : dernier outil utilisé, code pays, position du bouton du panneau et du panneau lui-même, taille du panneau et s'il occupe toute la fenêtre, langue de l'interface et date à laquelle vous l'avez choisie, si l'outil « Supprimés » conserve les messages supprimés et modifiés, date de votre dernière ouverture de l'outil « Supprimés », date de votre première ouverture du panneau, et si et quand TwoTicks vous a demandé de l'évaluer (cette demande n'est posée qu'une seule fois) ;
  - une note technique concernant la mise en route : les noms des éléments du code propre à WhatsApp Web que TwoTicks attendait lors du chargement de la page et que WhatsApp ne possède plus (cinq noms au maximum, chacun accompagné de l'heure à laquelle il a été relevé ; un nom est effacé au bout de sept jours, ou dès que WhatsApp dispose à nouveau d'un tel élément). Cela évite que les chargements ultérieurs de la page ne les attendent à nouveau et ne révèle aucune information vous concernant, ni sur vos discussions, ni sur la manière dont vous utilisez TwoTicks ;
  - les dernières informations fournies au panneau par l'extension : si l'option « Envoyer même lorsque WhatsApp Web est fermé » est activée, quels sont le service et le modèle d'IA configurés, quels types de contenu peuvent être envoyés en plus du texte (images, fichiers PDF, messages vocaux) ; pour le modèle intégré à Chrome, les langues prises en charge par Chrome et la quantité de texte qu'il peut traiter ; ainsi que les noms et les textes de vos instructions d'IA enregistrées. Pas de clé API.
- **Dans l'espace de stockage propre à l'extension**, sur cet appareil uniquement. La page WhatsApp et les autres sites web ne peuvent pas y accéder :
  - la date et l'heure de la première exécution de l'extension ainsi que la version sous laquelle elle a été créée, afin de pouvoir distinguer les différentes installations si des formules payantes venaient à être proposées (voir « TwoTicks est gratuit ») ;
  - le service d’IA que vous avez choisi ; votre clé API pour chaque service que vous avez configuré (chacune reste en place jusqu’à ce que vous la supprimiez) ; le modèle choisi pour chaque service et la liste des noms de modèles proposés par chaque service à votre compte ; l’adresse d’un serveur d’IA sur votre propre ordinateur ; l’identifiant de l’espace de travail Anthropic que vous avez saisi, le cas échéant ; la taille de la fenêtre de texte indiquée par Chrome pour son modèle intégré (un chiffre) ; vos limites de requêtes ; et les services et modèles pour lesquels vous avez désactivé la vérification avant l’envoi ;
  - vos instructions d'IA enregistrées ;
  - un journal des 300 dernières requêtes adressées à l'IA : heure, service, modèle, type de tâche, nombre de caractères envoyés, nombre et taille totale des images, fichiers PDF et enregistrements vocaux envoyés, nombre de tokens et résultat (réponse ou erreur). Le journal ne contient ni le texte des messages, ni les réponses, ni les noms ni le contenu des fichiers ;
  - la langue d'interface que vous avez choisie dans le menu contextuel de la barre d'outils ou sur la page des paramètres, ainsi que le moment où vous l'avez sélectionnée. L'extension transmet ce choix au panneau TwoTicks sur la page WhatsApp, afin que celui-ci s'ouvre dans la langue que vous avez choisie ;
  - la taille et l'emplacement de la fenêtre dans laquelle vous ouvrez WhatsApp Web avec TwoTicks (« Ouvrir dans sa propre fenêtre »), afin qu'elle s'ouvre de la même manière la prochaine fois ;
  - tant que le panneau de TwoTicks est ouvert dans une fenêtre distincte : les numéros attribués par Chrome à cette fenêtre et à son onglet, afin que l'extension puisse retrouver la fenêtre. Ces numéros sont effacés lorsque la fenêtre se ferme (si l'onglet de WhatsApp Web se ferme en premier : au prochain démarrage de WhatsApp Web, ou lors du redémarrage de Chrome) ;
  - tant que la fenêtre des tutoriels vidéo est ouverte : le numéro attribué par Chrome à cette fenêtre, afin que la vidéo suivante s'ouvre dans la même fenêtre. Ce numéro est effacé à la fermeture de la fenêtre et à chaque démarrage de Chrome ;
  - pour l'envoi lorsque WhatsApp Web est fermé : si cette fonctionnalité est activée, les heures d'envoi des prochains messages programmés et des messages automatiques (jusqu'à 30 ; uniquement les heures, sans destinataire ni texte) et s'il y en a d'autres à venir, ainsi que l'heure et le résultat de la dernière fois où l'extension a ouvert WhatsApp Web à cette fin (nombre de messages envoyés ou ayant échoué) ;
  - pour la connexion pour les programmes d'IA (MCP) : si elle est activée et quand vous y avez consenti, les groupes d'outils que vous avez activés, si vous confirmez sur WhatsApp Web, les programmes d'IA que vous avez autorisés ou refusés (le nom que chacun se donne, quand vous avez décidé et quand il a utilisé TwoTicks pour la dernière fois), si TwoTicks a ouvert WhatsApp Web dans une fenêtre distincte pour eux (le numéro de la fenêtre, jusqu'à sa fermeture) et un journal des 200 derniers appels (heure, programme, outil et résultat). Le journal ne contient rien de ce qui a été lu, envoyé ou enregistré ;
  - une copie des données que TwoTicks conserve à votre sujet dans l'espace de stockage du site web.whatsapp.com (mentionné ci-dessus) : les messages programmés, les réponses rapides, les messages de compliment, les paramètres de l'écran de confidentialité, les discussions marquées ou mises de côté dans « Sans réponse », les numéros récents de l'outil de messagerie directe, les heures d'envoi des messages vers plusieurs discussions et vos paramètres ; cela n'inclut pas l'historique des messages supprimés ou modifiés. WhatsApp Web vide son espace de stockage lorsqu’il se déconnecte de ce navigateur (par exemple lorsque le téléphone supprime l’appareil associé) ; lorsque le même compte WhatsApp se reconnecte ici, TwoTicks rétablit ce qui manque et vous en informe. La copie appartient à un seul compte et est classée sous un code calculé à partir de l’identifiant WhatsApp de ce compte : lorsqu’un autre compte se connecte ici, la copie du compte précédent est supprimée. Elle suit chaque modification en moins d’une seconde ; une copie non mise à jour depuis 30 jours n’est plus utilisée et est supprimée, tout comme celle dont la taille dépasserait 250 000 caractères. Contrairement au reste de cet espace de stockage, cette copie peut être demandée depuis la page de WhatsApp Web, à l’instar de l’espace de stockage du site qu’elle copie.
- **En mémoire uniquement** : tant que WhatsApp Web est ouvert, les messages récents sont conservés en mémoire afin qu’un message supprimé ultérieurement puisse encore être affiché (sauf lorsque l’outil « Supprimés » est désactivé) ; le résultat de la recherche « Sans réponse », de l'analyse des discussions et du résumé de l'ensemble des discussions, les mots des messages vocaux qui ont été transcrits, la dernière réponse de l'IA et les suggestions de compliments de l'IA sont conservés de la même manière. Tout cela est supprimé lorsque l'onglet est fermé.

## Utilisation des données

Les données sont utilisées uniquement pour la fonctionnalité que vous utilisez : exporter, analyser, envoyer les messages que vous rédigez ou programmez, vous rappeler les compliments que vous avez prévus (et les envoyer, si vous avez choisi cette option pour une routine), afficher les messages supprimés ou modifiés et, lorsque vous en faites la demande, obtenir une réponse de votre service d'IA. Les messages que vous envoyez via l'extension sont envoyés par WhatsApp Web depuis votre propre compte, de la même manière que les messages que vous tapez vous-même, et uniquement après que vous ayez lancé l'action (les messages destinés à plusieurs discussions ne sont envoyés qu'après confirmation du texte et des destinataires).

**Envoi lorsque WhatsApp Web est fermé.** Afin qu’un message programmé ou un compliment automatique soit envoyé à l’heure prévue même lorsqu’aucun onglet WhatsApp Web n’est ouvert, l’extension déclenche une alerte dans Chrome peu avant l’heure prévue. Si aucun onglet WhatsApp Web n’est ouvert à ce moment-là, elle ouvre WhatsApp Web dans une fenêtre minimisée sur votre ordinateur ; WhatsApp Web envoie alors ce qui doit l’être depuis votre compte, comme il le ferait dans un onglet que vous auriez ouvert, puis la fenêtre se referme. Aucune donnée n'est transmise à moi ni à aucun autre serveur dans ce cadre. Vous pouvez désactiver cette fonctionnalité dans les paramètres de l'extension (« Envoi »). Si vous cochez également « Laisser Chrome tourner en arrière-plan » à cet endroit, Chrome continue de fonctionner après la fermeture de ses fenêtres et redémarre lorsque vous vous connectez à votre ordinateur (autorisation « en arrière-plan » de Chrome) ; décochez cette case pour désactiver cette fonctionnalité.

L'analyse des conversations, le résumé de l'ensemble des conversations (« Aujourd’hui »), l'extraction des dates et heures à partir des messages, les fichiers de calendrier générés à partir de ceux-ci et les suggestions de réponse dans l'outil « Sans réponse » s'exécutent entièrement sur votre appareil. Deux éléments peuvent envoyer des données, mais uniquement si vous le choisissez et le confirmez dans la fenêtre affichant les éléments à envoyer : une demande urgente de résumé émanant de votre service d’IA, et les messages vocaux transcrits par votre service d’IA lorsque le modèle propre à Chrome ne peut pas le faire sur votre ordinateur (ces deux cas sont décrits sous « L'assistant IA avec votre propre clé API »). « Ajouter au planificateur » ne fait que remplir le planificateur : rien n’est programmé ni envoyé tant que vous n’avez pas cliqué sur le bouton correspondant. « Copier le prompt IA » copie les messages récents d’une conversation dans votre presse-papiers ; ils ne sont transférés que là où vous les collez.

## TwoTicks est gratuit

TwoTicks est gratuit. Il n'y a ni compte, ni paiement, ni licence, et l'extension ne fait appel à aucun service de paiement.

L'extension enregistre la date et la version de sa première exécution dans son propre espace de stockage sur votre appareil, afin de pouvoir distinguer les différentes installations si des formules payantes venaient à être proposées. Ces informations ne quittent jamais votre navigateur.

Si des formules payantes devaient être proposées dans une version ultérieure, cette politique sera mise à jour avant tout contact avec un prestataire de services de paiement.

## L'assistant IA avec votre propre clé API

L'assistant IA est facultatif et désactivé par défaut jusqu'à ce que vous le configuriez dans les paramètres. Vous pouvez choisir entre le modèle intégré à Chrome, qui ne nécessite pas de compte, et un service que vous utilisez avec votre propre compte :

| Service | Prestataire | Politique de confidentialité |
|---|---|---|
| Le modèle intégré à Chrome | fonctionne sur votre propre ordinateur, dans Chrome | — |
| Anthropic Claude | Anthropic PBC, États-Unis | https://www.anthropic.com/legal/privacy |
| OpenAI | OpenAI, États-Unis | https://openai.com/policies/privacy-policy |
| Google Gemini | Google LLC, États-Unis / Google Ireland Ltd. | https://policies.google.com/privacy |
| Mistral AI | Mistral AI SAS, France | https://legal.mistral.ai/terms/privacy-policy |
| OpenRouter | OpenRouter, Inc., États-Unis | https://openrouter.ai/privacy |
| Serveur local (Ollama, LM Studio) | fonctionne sur votre propre ordinateur | — |

- **Votre clé API** est conservée dans le stockage propre à l'extension sur votre appareil. Elle n'est transmise qu'au service auquel elle appartient, à chaque requête (à Anthropic, accompagnée de l'identifiant de l'espace de travail, si vous en avez saisi un). Je n'ai jamais accès à ces informations non plus.
- **Quelles informations sont envoyées, et quand ?** Ce n’est que lorsque vous lancez une requête et que vous la confirmez que l’extension envoie à votre service : votre instruction (par exemple « résumer »), la date du jour et votre heure locale (informations ajoutées par TwoTicks, afin que le modèle puisse distinguer ce qui appartient au passé de ce qui est encore à venir), le nom de la conversation et les messages que vous avez sélectionnés (date, heure, nom de l’expéditeur tel qu’il apparaît dans WhatsApp ou, en l’absence de nom enregistré, le numéro de téléphone, le texte et les légendes, les localisations partagées avec leurs coordonnées, les noms figurant sur les fiches de contact partagées, les questions et options de sondage ; pour les photos, les messages vocaux et autres médias, uniquement leur type ou leur nom de fichier ; le fichier lui-même uniquement si vous le choisissez, comme indiqué ci-dessous). Si vous cochez « Documents » dans l’assistant IA, le texte des documents que vous y avez sélectionnés est également inclus (fichiers Word, Excel et fichiers texte de la conversation ; l’extension les convertit en texte brut sur votre appareil et envoie ce texte, et non le fichier). Si vous cochez « Images », les images que vous y avez sélectionnées sont également transmises : chacune est recréée sur votre appareil sous la forme d’une image JPEG de plus petite taille (1 568 pixels de côté au maximum), de sorte que seule l’image elle-même est envoyée, et non les données enregistrées par l’appareil photo dans le fichier. Les fichiers PDF que vous avez sélectionnés sous « Documents » sont transmis tels quels, lorsque le service prend en charge les fichiers PDF ; lorsqu’il ne les prend pas en charge (et avec le modèle intégré à Chrome), l’extension extrait le texte du fichier PDF sur votre appareil et envoie ce texte, et non le fichier (un PDF numérisé, qui contient des images de ses pages et aucun texte, est ignoré). Un fichier PDF protégé par un mot de passe est également exclu, tant en tant que fichier qu’en tant que texte. Si vous cochez « Messages vocaux », les messages vocaux que vous avez sélectionnés à cet endroit sont d’abord transcrits. Lorsque le modèle intégré à Chrome se trouve sur votre ordinateur et peut y écouter les enregistrements, cette opération s’effectue sur votre propre ordinateur, quel que soit le service d’IA que vous utilisez pour la requête : l’enregistrement lui-même n’est transmis à aucun service. Lorsque ce n’est pas le cas (le modèle n’a pas été téléchargé ou votre ordinateur ne peut pas l’exécuter) et que le service d’IA que vous utilisez est capable de transcrire lui-même la parole (actuellement Google Gemini et OpenAI), c’est ce service qui s’en charge : l’enregistrement est alors transmis à ce service, avec votre mot de passe, comme pour toute autre requête. Avant l’envoi de chaque enregistrement, la confirmation l’affiche à l’aide d’un lecteur permettant de l’écouter, en indiquant qui l’a envoyé, à quel moment et sa durée ; cette confirmation ne peut pas être désactivée, et si vous annulez, l’enregistrement n’est pas envoyé. Lorsque ni l’une ni l’autre de ces options n’est possible, les messages vocaux ne sont pas proposés. Il en va de même dans « Sans réponse » et dans l’analyse du chat, où un enregistrement n’est transmis à un service qu’après une action de votre part (dans « Sans réponse », le bouton situé dans la ligne d’un chat, ou « Rédiger avec l’IA » pour les messages vocaux qui vous sont adressés, les deux uniquement lorsque « Transcrire les messages vocaux » y est coché ; dans l’analyse de discussion, l’option, qui est désactivée jusqu’à ce que vous la cochiez) et jamais de manière automatique. Par la suite, seuls les mots sont transmis, dans le cadre du texte de la requête, où la confirmation les affiche avant tout envoi. Les images ne sont proposées que si le service et le modèle que vous utilisez les prennent en charge ; un fichier PDF est transmis sous forme de fichier lorsque le service accepte les fichiers PDF, et sous forme de texte dans les autres cas ; une requête peut contenir au maximum dix images et cinq documents, et ne comprend jamais d'éléments provenant de messages envoyés pour être consultés une seule fois. Comme tout site web, le service détecte également votre adresse IP. Chrome vous demande votre autorisation avant que l’extension ne puisse entrer en contact avec un service. La confirmation affiche la requête complète, y compris les instructions ajoutées par TwoTicks, exactement telle qu’elle sera envoyée, à chaque fois ; elle affiche chaque image jointe et nomme chaque fichier PDF, en précisant qui l’a envoyé dans le chat et à quel moment. Avant qu’un enregistrement vocal ne soit transmis à un service, l’extension affiche l’enregistrement lui-même à l’aide d’un lecteur, le service et le modèle auxquels il est destiné, ainsi que les mots clés qui l’accompagnent si le service en a reçu ; un enregistrement que votre navigateur ne peut pas lire n’est pas envoyé. Cette information est générée par l’extension elle-même, hors de portée de la page WhatsApp et des autres scripts qui s’y exécutent, de sorte que rien d’autre ne peut modifier ce qu’elle affiche ou envoyer en votre nom. Si vous cochez « Ne plus afficher » pour un service et un modèle, les requêtes ultérieures adressées à celui-ci seront envoyées sans cette confirmation, immédiatement après un clic sur un bouton IA ; un script malveillant s'exécutant sur la page de WhatsApp pourrait alors utiliser l'un de vos clics pour déclencher une telle requête ; vous pouvez réactiver cette option dans les paramètres (« Avant chaque demande à l’IA »), et elle réapparaîtra d’elle-même pour un autre service ou modèle, ou lorsque vous supprimerez la clé. Une requête contenant des images ou des fichiers PDF en pièce jointe affiche toujours la fenêtre de confirmation, quel que soit votre choix, tout comme chaque enregistrement vocal envoyé à un service. Le texte d’un document, y compris celui d’un fichier PDF, fait partie du corps de la requête, pour lequel votre choix « Ne plus afficher » s’applique. Pour le résumé de toutes les conversations (« Aujourd’hui » dans l’analyse des conversations), rien n’est envoyé à moins que vous ne choisissiez « Classer par urgence avec l’IA » à cet endroit ; dans ce cas, ce sont les lignes répertoriées dans le résumé qui sont transmises (pour chacune : le nom de la conversation, l’expéditeur, la date, l’heure et le texte de ce message), et non les conversations dont elles sont issues. Pour les idées de compliments, l’extension envoie les notes, le ton et la langue que vous avez choisis, ainsi que les compliments déjà présents dans votre liste ; le nom de la personne et votre conversation avec elle ne sont transmis que si vous cochez « Laisser l’IA lire nos 30 derniers messages ».
- **La réponse** s'affiche dans le panneau. Si vous le souhaitez, elle est placée dans la zone de saisie de WhatsApp, sans être envoyée. L'extension ne la conserve pas.
- **Le service** traite la demande conformément à ses propres conditions générales et à sa politique de confidentialité, via votre compte, et vous facture son utilisation. Certains services conservent les requêtes pendant une durée limitée, par exemple pour détecter les abus ; vérifiez les paramètres de votre compte à cet égard. Les services basés en dehors de l'UE (marqués « USA » ci-dessus) reçoivent les données dans leur pays ; le service est responsable des garanties requises pour de tels transferts (telles que le cadre de protection des données UE-États-Unis ou les clauses contractuelles types). Avec un serveur local, les données ne quittent pas votre ordinateur. Les modèles cloud d’Ollama constituent une exception (leur nom contient « cloud », par exemple « gpt-oss:120b-cloud ») : Ollama transmet ces requêtes à ses propres serveurs (ollama.com, États-Unis) conformément à ses propres conditions d’utilisation. TwoTicks ne choisit jamais ce type de modèle de son propre chef, et la confirmation précise le nom du modèle et indique que la requête est transmise à Ollama Cloud.
- **Le modèle intégré à Chrome** fait partie du navigateur Chrome (Google l'appelle « Gemini Nano »). Grâce à lui, la requête est traitée directement dans votre navigateur, sur votre propre ordinateur : l'extension ne l'envoie à aucun service, n'a besoin d'aucune clé et ne demande aucune autorisation à Chrome pour y accéder. Selon Google, aucune donnée n’est transmise à Google ni à quiconque lorsque le modèle est utilisé. Le modèle lui-même ne fait pas partie de TwoTicks : Chrome le télécharge une seule fois depuis les serveurs de Google lorsque vous cliquez sur « Télécharger le modèle » dans les paramètres, au moment où il télécharge ses propres mises à jour ; aucune information issue de vos conversations n’est transmise lors de ce téléchargement. La vérification avant l’envoi affiche la requête de la même manière que pour un service. Lorsque Chrome indique que le modèle peut consulter des images sur votre ordinateur, les images que vous avez choisies lui sont également transmises à ce moment-là ; pour un fichier PDF, il récupère le texte lu sur votre appareil. Lorsqu’il peut écouter sur votre ordinateur, il enregistre également les messages vocaux que vous avez choisis, pour chaque service d’IA que vous pourriez utiliser.
- **Formules gratuites.** Certains services proposent des formules gratuites ou des modèles gratuits (signalés par « gratuit avec limites » dans les paramètres). Avec ces formules, le service peut utiliser ce que vous envoyez pour améliorer ses modèles, et son personnel peut en prendre connaissance : c'est le cas, par exemple, de l'offre gratuite de Google Gemini en dehors de l'UE, de l'EEE, de la Suisse et du Royaume-Uni, des modèles gratuits d'OpenRouter (en fonction des paramètres de votre compte et du fournisseur derrière chaque modèle) et éventuellement de la formule gratuite de Mistral AI. Vos conversations contiennent les propos et les noms d’autres personnes ; un forfait payant ou un modèle installé sur votre propre ordinateur constitue donc le choix le plus sûr. Les paramètres affichent cet avertissement à côté de ces services, et TwoTicks ne sélectionne jamais de lui-même un modèle gratuit ; vous pouvez toutefois en choisir un.
- **Les limites de requêtes** par heure et par jour, que vous pouvez modifier, empêchent l'extension d'envoyer plus de requêtes que prévu.

Les messages que vous envoyez à un service d'IA contiennent les propos et les noms d'autres personnes, et un message vocal correspond à la voix d'une autre personne. Dans le cadre d'un usage personnel, cela relève généralement de votre vie privée. Si vous utilisez l'assistant IA à des fins professionnelles, vous devez disposer d'une base juridique pour l'envoi de ces données, éventuellement sous la forme d'un accord de traitement des données conclu avec le service d'IA, et vous ne devez pas transmettre de catégories particulières de données (par exemple, des données relatives à la santé) sans consentement. Consultez les Conditions d'utilisation.

## Programmes d'IA sur votre ordinateur (Connexion, MCP)

La connexion pour les programmes d'IA est facultative et désactivée jusqu'à ce que vous l'activiez dans les paramètres (« Connexion (MCP) »), après y avoir lu ce qu'elle fait et l'avoir acceptée. Elle permet aux programmes d'IA qui s'exécutent sur votre propre ordinateur et parlent le Model Context Protocol (MCP), par exemple Claude Code ou VS Code, d'utiliser les outils de TwoTicks. Elle nécessite le programme gratuit distinct « TwoTicks MCP », que vous installez vous-même depuis le site web de TwoTicks (il ne fait pas partie de l'extension), et l'autorisation de Chrome « Communiquer avec les applications natives associées » (nativeMessaging), que l'extension demande lorsque vous activez la connexion et rend lorsque vous la désactivez.

- **Fonctionnement.** Tant que la connexion est active, Chrome lance le programme TwoTicks MCP sur votre ordinateur ; seul TwoTicks peut le lancer et lui parler. Les programmes d'IA que vous utilisez lancent eux aussi TwoTicks MCP ; il transmet leurs requêtes à l'extension et renvoie les réponses de l'extension vers eux, sur votre ordinateur. Chaque programme d'IA doit d'abord être autorisé par vous, une seule fois, dans les paramètres ou dans une fenêtre que TwoTicks affiche sur WhatsApp Web ; vous pouvez le retirer à cet endroit à tout moment. Un programme d'IA se donne lui-même un nom, et un autre programme sur votre ordinateur pourrait se donner le même nom : n'autorisez que les programmes que vous avez lancés vous-même.
- **Ce que les programmes d'IA peuvent faire.** Dans les groupes d'outils que vous activez (lecture ; envoi et planification ; fichiers ; lecture de documents et de messages vocaux ; l'écran de confidentialité ; messages supprimés et modifiés, qui reste désactivé tant que vous ne l'activez pas) : lire votre liste de conversations, vos conversations et vos messages, les résultats de l'analyse des conversations, « Aujourd’hui » et « Sans réponse », vos messages programmés, vos routines de compliments et vos réponses rapides ; récupérer les pièces jointes d'une conversation (images, documents, messages vocaux, vidéos ; jamais les médias envoyés pour être vus une seule fois) ; lire le texte des documents et faire transcrire les messages vocaux sur votre ordinateur par le modèle intégré de Chrome ; activer et désactiver l'écran de confidentialité ; et préparer des messages, des messages à plusieurs conversations, des messages programmés, des routines de compliments, des réponses rapides et des exportations. Les conversations dont les membres ont activé la confidentialité avancée des discussions de WhatsApp ne sont pas transmises. Les listes de membres des groupes ne sont pas disponibles.
- **Votre confirmation.** Rien n'est envoyé, programmé, supprimé, modifié ou exporté sans votre confirmation de ce qui va se passer exactement (le texte, les destinataires et, pour plusieurs conversations, que les destinataires ont accepté de recevoir le message et qu'il ne s'agit pas de publicité). Le programme d'IA vous montre cette confirmation là où il le peut (sous forme de formulaire propre) ; sinon, ou si vous le choisissez dans les paramètres, TwoTicks l'affiche sur WhatsApp Web dans une fenêtre distincte que la page de WhatsApp ne peut ni lire ni modifier. Vous pouvez y corriger le texte d'un message avant de le confirmer et, quand plusieurs messages attendent ensemble, en écarter certains ; le programme d'IA est alors informé du texte qui est parti et des messages que vous avez écartés. Un programme d'IA que vous configurez pour répondre seul à ces formulaires (par exemple avec un script ou un hook de votre cru) répond en votre nom. Les messages envoyés ainsi comptent dans les limites de TwoTicks : au moins 15 secondes entre deux messages et au plus 30 messages en 24 heures.
- **Où vont les données.** TwoTicks n'envoie lui-même rien sur Internet pour cela : les données vont de l'extension à TwoTicks MCP, puis de là au programme d'IA sur votre ordinateur. Ce qui se passe ensuite dépend de ce programme d'IA : la plupart envoient ce qu'ils lisent à l'entreprise qui exploite leur modèle d'IA (par exemple Anthropic pour Claude Code, ou GitHub pour Copilot dans VS Code), selon les conditions et la politique de confidentialité de cette entreprise et avec votre compte chez elle. Les conversations contiennent les mots, les noms et les voix d'autres personnes ; si vous l'utilisez pour le travail, il vous faut une base légale pour les transmettre (voir les Conditions d'utilisation). Les paramètres d'IA et les clés API de l'extension ne sont jamais utilisés pour un programme d'IA et ne lui sont jamais remis.
- **Fichiers.** Les pièces jointes et les exportations demandées par un programme d'IA sont enregistrées par TwoTicks MCP sur votre ordinateur : dans un dossier « twoticks-files » situé dans le dossier où travaille le programme d'IA (tenu hors de git par un fichier .gitignore), ou sinon dans Documents\TwoTicks MCP. Elles sont marquées comme provenant d'Internet, comme un téléchargement du navigateur, et les programmes (fichiers exécutables) ne sont jamais enregistrés. Elles y restent jusqu'à ce que vous les supprimiez.
- **Ce qui est conservé.** L'extension conserve les paramètres et le journal décrits sous « Où sont stockées les données ? » ; une action qui attend votre confirmation n'est gardée qu'en mémoire, jusqu'à ce qu'elle soit effectuée ou pendant dix minutes. TwoTicks MCP conserve, dans votre dossier utilisateur, ses propres fichiers de programme, son enregistrement auprès de Chrome (et, si vous l'avez choisi, de Claude Code et de VS Code) et, pendant qu'il s'exécute, le nom du canal entre ses parties avec une clé aléatoire que seuls les programmes capables de lire votre dossier utilisateur peuvent utiliser ; il ne conserve aucune conversation.
- **Désactivation.** Désactiver la connexion y met fin immédiatement et rend l'autorisation à Chrome. « Vider le journal » vide le journal ; « Retirer » retire un programme d'IA. La commande « npx twoticks-mcp uninstall » supprime TwoTicks MCP avec ses enregistrements ; les fichiers enregistrés restent jusqu'à ce que vous les supprimiez.

## Conservation et suppression

Les données restent dans votre navigateur jusqu'à ce que vous les supprimiez :

- « Effacer » dans l'outil « Supprimés » supprime l'historique des messages supprimés et modifiés.
- Dans le Planificateur, le symbole « × » sur un message en attente permet de l'annuler, tandis que « Effacer l’historique » supprime les entrées antérieures.
- Dans Compliments, l'icône de la corbeille associée à une routine permet de la supprimer, ainsi que ses compliments et ses notes.
- Le « × » situé à côté d'un numéro récent permet de le supprimer de l'outil de messagerie privée.
- Dans la rubrique « Réponses rapides », l'icône représentant une corbeille permet de supprimer une réponse.
- « Afficher à nouveau » dans l'outil « Sans réponse » efface les discussions que vous avez marquées comme « Pas besoin de répondre » (ou « Pas besoin de réponse ») ainsi que celles que vous avez mises de côté avec « Me le rappeler plus tard » ; une conversation est également oubliée d'elle-même lorsqu'un nouveau message y arrive, et une conversation mise de côté le jour même où elle réapparaît.
- Dans les paramètres : « Supprimer la clé » supprime la clé API du service affiché, ainsi que la liste de ses modèles ; « Supprimer » supprime une instruction enregistrée ; « Vider le journal » vide le journal des requêtes IA.
- Dans l'onglet « Connexion (MCP) » des paramètres : « Retirer » retire un programme d'IA, « Vider le journal » vide le journal des appels, et désactiver la connexion y met fin et rend l'autorisation à Chrome. La commande « npx twoticks-mcp uninstall » supprime TwoTicks MCP de votre ordinateur ; les fichiers qu'il a enregistrés pour les programmes d'IA restent jusqu'à ce que vous les supprimiez.
- La copie de vos données stockée sur le site de WhatsApp Web (voir ci-dessus) suit les modifications que vous effectuez dans TwoTicks. La suppression des données du site web.whatsapp.com n'entraîne pas leur suppression ; celles-ci sont supprimées lorsqu'un autre compte WhatsApp se connecte à ce site, lorsqu'elles n'ont pas été renouvelées depuis 30 jours ou lorsque vous désinstallez l'extension.
- La désinstallation de l'extension supprime ses propres données stockées (l'heure et la version de son premier lancement, les clés API, les instructions, le journal des requêtes, la langue que vous avez choisie et la copie de vos données provenant du stockage du site WhatsApp Web) ; une copie des noms et des textes de vos instructions reste toutefois dans le stockage du site WhatsApp Web (voir ci-dessous). Elle ne supprime pas ce que l'extension a stocké dans le stockage du site web.whatsapp.com. Pour supprimer également ces données, effacez les données du site web.whatsapp.com dans Chrome (Paramètres > Confidentialité et sécurité > Cookies tiers > Afficher toutes les données et autorisations du site). Cela vous déconnectera également de WhatsApp Web.

Les fichiers exportés vous appartiennent et restent sur votre ordinateur jusqu'à ce que vous les supprimiez. Les données que vous avez envoyées à un service d'IA y sont conservées conformément aux règles de ce service.
